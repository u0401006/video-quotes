# Data Renegades: Simon Willison 金句 30 句 (中英對照)

來源：https://www.youtube.com/watch?v=r1J4KQAMxik

1. "I build open-source software for data journalism and my cunning plan here is journalists have no money. I'll give it to them for free."
   我為資料新聞學開發開源軟體，我的狡猾計畫是：記者通常沒錢，所以我就免費提供給他們。

2. "Everyone else in the world with money needs the same tools."
   世界上其他有錢的人也都需要一樣的工具。

3. "There's no competition in this space. It's all about trying to figure out what is the most value we can get out of this technology as an industry as a whole."
   這個領域沒有競爭。一切都在於我們如何以整個產業的角度，從這項技術中榨取最大的價值。

4. "Everything is in scope for a journalist. You're telling stories about the world."
   對記者來說，任何事物都在探討範圍內。你是在講述關於這個世界的故事。

5. "If you give your audience a searchable database to back up the story that you're presenting, that's a great way of building more credibility."
   如果你能提供一個可搜尋的資料庫來支持你報導的故事，這將是建立更高公信力的絕佳方式。

6. "It's a very noble thing to then spread that out and make sure that those smaller local publications can work off the same data."
   將這些資源傳播出去，確保那些較小的地方刊物也能使用相同的資料，這是一件非常高尚的事。

7. "The business model for journalism is in a pretty bad shape at the moment. But there's a whole new set of nonprofit newsrooms who are doing fantastic work."
   新聞業現今的商業模式狀況相當糟糕。但有一整批新興的非營利新聞編輯室正在進行出色的工作。

8. "I like this idea of building a multi-tool. My ultimate goal is any problem you have with data, there should be a plugin that lets you do that."
   我喜歡打造「多功能工具」這個想法。我的終極目標是：無論你遇到什麼資料問題，都應該有一個外掛能幫你解決。

9. "That's the best and the worst thing about open source. The best thing is that anyone in the world can use it. The worst thing is they never tell you."
   開源最好也最壞的地方就在於：最好的是全世界任何人都可以使用它，最壞的是他們永遠不會告訴你。

10. "Having really good habits about keeping that pipeline documented and clean and repeatable, I still think is a problem."
    保持良好的習慣，讓資料處理流程有完善的文件記錄、乾淨且可重複執行，我認為這至今仍是個問題。

11. "Git is notoriously difficult to use. It's a fabulously obtuse piece of software, but it does unlock so much if you can build those sort of organizational habits around it."
    Git 以難用出名。這是一款極度遲鈍的軟體，但如果你能圍繞它建立起組織習慣，它就能解鎖無數潛能。

12. "Everyone says, I spend 95% of my time cleaning the data and I hate it."
    每個人都說：我花了 95% 的時間在清理資料，而且我討厭這件事。

13. "If it takes you six months to do an analysis, the news cycle has moved on."
    如果你要花六個月才能做完一項分析，新聞週期早就過去了。

14. "Every production database is changing. The schema changes all the time."
    每個正式環境的資料庫都在變動。它的架構總是無時無刻在改變。

15. "I don't think most data teams think in terms of API contracts that you're making to your users."
    我認為大多數的資料團隊並沒有以「對用戶建立 API 契約」的思維在思考。

16. "Good tools reduce friction in a way that encourages a culture in a certain direction."
    好的工具能以減少摩擦力的方式，鼓勵文化朝特定方向發展。

17. "If you smooth the right cow paths, people will naturally head in those directions."
    如果你把正確的捷徑鋪平，人們自然就會朝那個方向前進。

18. "I never want to see a business report that doesn't have a way of me getting to the queries and actually auditing how that report was produced."
    我絕對不想看到一份商業報告，卻沒有辦法讓我查看查詢語法，並實際審核該報告是如何產生的。

19. "If people lose trust in the official documentation it takes years to earn that trust back again."
    如果人們對官方文件失去信任，那將需要花上好幾年的時間才能重新贏回信任。

20. "If you're the person who builds the search engine, you secretly control the company."
    如果你是那個建立搜尋引擎的人，你就在暗中控制了整間公司。

21. "Be a little bit renegade. Start writing documentation. Don't promise that it's going to stay up to date in the future."
    當個有點叛逆的人吧。開始寫文件，而且不要承諾它未來一定會保持最新。

22. "I've been a professional software engineer for 25 years... you still don't know everything. You should still celebrate figuring out how to learn four loops in bash."
    我當了 25 年的專業軟體工程師……你依然不可能無所不知。你還是應該為自己學會了怎麼在 bash 寫 for 迴圈而慶祝。

23. "The terminal is now accessible to people who never learned the terminal before because the LLM knows the commands for you."
    從沒學過終端機的人現在也能使用它了，因為大型語言模型 (LLM) 會替你記住那些指令。

24. "Data cleaning is basically a case of curl this thing, download it here, load it up into Python pandas. They (LLMs) are so good at that stuff right now."
    資料清理基本上就是：用 curl 抓取、下載到這裡、載入 Python Pandas。大型語言模型現在非常擅長做這些事。

25. "I am liberated to think at a higher level about the code that I'm writing because I don't have to type every line of Python myself."
    我被解放了，可以從更高的層次思考我正在寫的程式碼，因為我不再需要親自敲下每一行 Python。

26. "I feel like the future of those BI dashboard tools is they have to be prompt driven. They just have to be."
    我覺得那些商業智慧 (BI) 儀表板工具的未來，勢必得是「提示詞驅動 (prompt-driven)」。它們非得如此不可。

27. "LLMs are stunningly good at outputting SQL queries, especially if you give them extra metadata about the columns."
    大型語言模型在輸出 SQL 查詢語句方面表現得驚為天人，特別是當你提供它們關於欄位的額外詮釋資料時。

28. "Data entry is now something which one of the most expensive parts of working with messy data. They (LLMs) do that so well in my experience they get it 95 to 98% right."
    資料輸入是處理雜亂資料時最昂貴的環節之一。根據我的經驗，大型語言模型把它做得太好了，正確率高達 95% 到 98%。

29. "The best tip is that if you're a showrunner, there is so much that you have to do... It is impossible for you to micromanage all of it."
    最好的建議是，如果你是一個節目統籌，你有太多事情要做了……你不可能微觀管理所有細節。

30. "I think it's inexcusable to have executable code that has business value that is not in version control somewhere."
    我認為，擁有商業價值的可執行程式碼卻沒有放在任何版本控制中，這是不可原諒的。
